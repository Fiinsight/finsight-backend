# 시연 시드 검증 보고 — 2026-10-13

로컬 DB에 `--apply`로 세 시연 계정을 생성했습니다. 재실행 후 사용자 ID가 유지되고 기록이 중복되지 않는 것을 확인했습니다. 일반 계정·뉴스·용어·일반 사용자의 판단/메모/학습/숙련도는 실행 전후 행 수와 전체 행 내용 해시가 모두 동일했습니다. 환경 파일은 읽기만 했고 비밀번호·토큰·환경 값은 출력하지 않았습니다.

## 생성된 기록

| 계정 | 퀴즈 | 판단 | 기사 메모 | 숙련도 용어 | 연속 활동 |
|---|---:|---:|---:|---:|---:|
| 민지 | 25 | 0 | 1 | 8 | 5일 |
| 준호 | 30 | 0 | 5 | 8 | 10일 |
| 새 사용자 | 0 | 0 | 0 | 0 | 0일 |

기간은 실행일 포함 최근 14일입니다. 각 계정의 5일/10일 연속 활동 직전에는 활동 없는 날을 두었습니다. 새 사용자는 온보딩 답·완료 시각·수준 등도 초기화되어 있습니다. 읽기 기록은 서버에 없으므로 발표 기기에서 별도 스니펫을 실행해야 합니다.

실제 저장 문항 수준:

```
민지|beginner|25
준호|analyst|19
준호|normal|11
```

준호는 일반 문제를 규칙으로 판정할 수 있는 기사를 우선 사용했습니다. 특정 용어의 일반 문제가 부족하면 같은 용어의 실제 분석 문제로 대체하며 임의로 level을 붙이지 않습니다.

## 실제 API 비교

동일 기사 ID 1을 두 계정으로 열었으며 `level` 쿼리 파라미터는 보내지 않았습니다.

| 계정 | 기본 수준 | 복습 상위 3 | 약한 분야 | 수준 제안 | 퀴즈 | 연속 활동 |
|---|---|---|---|---|---|---:|
| demo-beginner | beginner | 기준금리, 환율, 금리 | 없음 | 아직 없음 | 이 기사에 등장하는 ‘금리’의 기본 의미는 무엇인가요? | 5 |
| demo-investor | analyst | 수급, 밸류에이션, 금리 | 없음 | 아직 없음 | 다음 중 기사에 나온 사실이 아닌 것은? | 10 |
차이 검증: 제한: 준호 약한 분야(저장 종가 부족 시 예상되는 제한)


프로필의 어려운 점은 민지 `terms`, 준호 `evidence`입니다. 초기 수준 제안은 둘 다 없습니다. 민지는 기준 직전이고 준호는 최고 수준이기 때문입니다. 민지에서 기사 7의 AI, 기사 55의 반도체 퀴즈를 실제 API로 하나씩 맞힌 뒤 `levelSuggestion=normal`을 확인했습니다. 이후 시드를 다시 적용하여 **25문항·제안 직전** 상태로 복원했습니다.

## 부족한 데이터와 한계

- 민지 판단 2건, 준호 금리·채권 6건/기업·종목 6건을 만들 정상 가격 자료가 부족합니다. 실제 값처럼 보이는 가짜 수익률은 만들지 않았습니다.
- DB에는 종가 두 개가 저장된 확정 판단 3건이 있지만 같은 기사·같은 가격 쌍입니다. 현재 회사명 매핑과 일치하지 않아 모두 제외했습니다. 기존 판단이나 뉴스의 오염된 매핑은 수정하지 않았습니다.
- 따라서 준호의 약한 분야와 구조화된 판단 피드백 장면은 이 DB에서 시연 준비가 끝나지 않았습니다. API 검증 스크립트는 이를 제한으로 표시하고 종료 코드 2를 반환합니다. 학습 수준·복습·퀴즈·연속 활동과 실시간 승급 제안은 확인되었습니다.
- 공개 로컬 모델의 실제 설치·평가나 리라이팅 품질 검증은 이번 시드의 범위가 아닙니다. 발표 대본에 규칙 대체와 데이터 한계를 명시했습니다.
