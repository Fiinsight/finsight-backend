# ML1 · 개념 숙련도와 맞춤 학습

사용자·용어마다 알고 있을 확률 `p_known`을 BKT(Bayesian Knowledge Tracing)로 갱신합니다. 외부 API·학습용 라이브러리·유료 LLM을 사용하지 않습니다. 확률은 실제 능력을 확정하는 점수가 아닌 모델의 추정입니다.

## 모델 식

직전 확률을 p, 실수 확률을 s, 모를 때 맞힐 확률을 g, 학습 전이를 t라고 하면:

- 정답 관찰: `posterior = p(1-s) / [p(1-s) + (1-p)g]`
- 오답 관찰: `posterior = ps / [ps + (1-p)(1-g)]`
- 답변 후 학습: `p_next = posterior + (1-posterior)t`

처음에는 p_init=0.3, p_learn=0.15입니다.

| 실제 문항 수준 | p_guess | p_slip |
|---|---:|---:|
| beginner (정의) | 0.33 | 0.10 |
| normal (기사 변화) | 0.30 | 0.15 |
| analyst (사실 구분) | 0.25 | 0.20 |

beginner의 0.33은 3지선다 추측 기준입니다. 나머지 수준별 수치는 문제 난이도를 반영하는 초기 가정이며, 실제 사용자 데이터로 보정한 추정치가 아닙니다. normal/analyst 요청이 beginner 문항으로 대체되면 **실제 출제 수준**의 파라미터로 갱신합니다. 추정기를 시작하려고 별도 데이터셋을 학습할 필요가 없으며 사용자의 답 하나부터 사전 확률을 갱신할 수 있습니다. 단, 답이 적을수록 초기 가정의 영향이 큽니다.

기초 모델 참고: [Corbett·Anderson, Knowledge Tracing](https://doi.org/10.1007/BF01099821).

## 사용 위치

- POST `/api/learning/news/{id}/answers`: 서버 채점 후 같은 트랜잭션에서 term_mastery를 갱신합니다. 최초 INSERT 충돌을 처리하고 해당 사용자·용어 행을 FOR UPDATE로 잠가 동시 갱신 유실을 방지합니다. 정답 인덱스는 공개하지 않습니다. 수락한 답변마다 attempts를 1 증가시킵니다.
- 출제: 출제 가능한 기사 용어 중 p_known ∈ [0.4,0.7] 우선, 없으면 최저 확률. 동률은 기존 기사 관련성 순서입니다. 새 용어는 0.3입니다. 열린 퀴즈의 용어는 숙련도가 바뀌어도 같은 원문으로 서버 채점할 수 있습니다.
- 복습: 용어별 가장 최근 기사 하나를 고르고 `effective = p_known × 0.97^경과일` 오름차순으로 최대 50개. 경과일은 한국 날짜 기준이며 미래 날짜는 0일입니다. 백필 전 이력이 있는 용어는 초기값을 사용합니다. 망각 가중은 조회 때만 적용하고 DB 확률을 일괄 변경하지 않습니다.
- 수준 제안: 마지막 답변 수준이 현재 수준인 서로 다른 용어 5개 이상에서 p_known ≥ 0.85면 다음 수준을 제안합니다. 기존 최근 30일 정답률 규칙은 대체됩니다. 사용자가 선택할 때만 수준을 저장합니다.
- progress.mastery: strongest/weakest 각 최대 3개와 totalAttempts, learningCount. 화면 막대는 망각 가중 확률을 표시하며 '최근 퀴즈 n회 기준 추정'으로 안내합니다. n은 저장된 숙련도 갱신 횟수 합이며 짧은 기간으로 잘라 낸 횟수가 아닙니다.

## 저장·수동 백필

V11은 `(user_id,term)` 기본키, p_known(0~1), attempts(0 이상), last_answered_at만 가진 term_mastery를 멱등 생성합니다. 과거 마이그레이션 내용·환경 파일·기존 데이터는 변경하지 않습니다.

`TermMasteryService.backfillCount()`는 아직 term_mastery가 없는 개념/저장 답변 수만 조회합니다. `backfillMissing()`은 관리자가 명시적으로 호출할 때만 시간·id 순서로 이력을 계산해 없는 개념을 INSERT하며 기존 숙련도를 덮어쓰지 않습니다. 스케줄러·앱 시작·API 요청에 백필을 연결하지 않았습니다. 반복 호출 및 실시간 답변과의 충돌은 ON CONFLICT DO NOTHING으로 처리합니다.

**실행하지 않은 백필 대상(2026-10-13, 로컬 DB 읽기 전용 확인): 개념 9개, 저장 답변 11개.** 운영 DB 대상 수는 미확인입니다. 현재 learning_progress는 문항별 마지막 답만 보관하므로 과거 재답변 횟수/순서 전체를 복원할 수 없습니다. 백필 attempts는 저장된 마지막 답변 수입니다.

## 검증

고정 정답·오답·혼합 시퀀스, 수준별 파라미터, 확률 범위, 망각/출제 경계/동률, 5개 개념 및 0.85 제안 경계를 검증합니다. 빈 PostgreSQL + prod 기동 테스트는 V1~V11 전체 migrate와 Hibernate validate, 실제 DB 숙련도 갱신/소유자 분리/수동 백필 멱등성을 검증합니다. 테스트 데이터는 격리 DB에서 롤백합니다.

용어 분류와 숙련도 표시: TOPIC 기록은 삭제하지 않고 조회에서 제외합니다. MARKET은 초보자 문항만 허용합니다. 잘 아는 개념은 망각 가중 확률 80% 이상·3회 이상, 다시 볼 개념은 50% 미만 또는 마지막 오답이며 나머지는 익히는 중으로 셉니다. 오늘의 용어는 핵심 뉴스의 CONCEPT 후보에서 이 기준과 미응답 여부로 고릅니다. 모델 식·파라미터·망각 가중은 동일합니다.
