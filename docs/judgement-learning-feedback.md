# 판단 대상과 학습 피드백

새 판단에 종목·지수 대상을 고정해 저장합니다. 포스코인터(047050) 등 별칭은 기존 회사 경계·본문 횟수 규칙을 그대로 따릅니다. 카카오톡을 카카오로 연결하지 않습니다. 정부 경제 기사도 개별 종목 없이 국내 시장을 대상으로 합니다.

판단일(휴장일이면 직전 거래일)과 다음 거래일의 실제 종가로 ±0.5% 방향을 채점합니다. 종목은 같은 두 날짜의 소속 시장 지수도 비교합니다. 기존 일봉/기간 캐시를 우선 쓰고, 없는 구간만 기존 KIS client로 요청합니다. 지수 시세가 누락되면 결과를 기다리며 임의 값으로 확정하지 않습니다.

기사 리드·제목의 방향 표현과 감성 힌트를 결과와 비교하고, 근거가 있으면 실제 문장을 인용합니다. CONCEPT 용어 중 사용자 effectivePKnown이 가장 낮고 현재 수준에서 출제 가능한 용어를 연결합니다. BKT·망각·출제 규칙은 변경하지 않습니다.

기존 판단은 수정하지 않았습니다. dry-run 대상 27건: 저장 종가로 즉시 재채점 가능한 건 0, 필요한 날짜/대상의 종가 부족 17, 대상 없음 7, 다음 거래일 대기 3. 종가가 저장된 전체 4건은 다른 날짜/대상이라 대상 판단의 결과를 대신 계산할 수 없습니다. 자세한 id/날짜는 judgement-regrade-dry-run.md에 있습니다. --apply는 구현/실행하지 않았습니다. 추가 가격 확보와 기존 판단 변경에는 별도 승인이 필요합니다.

검증: JUnit 190개 중 185 통과, prod DB 전용 5개는 로컬에서 제외(CI에서 빈 PostgreSQL로 V1~V15 migrate + validate). Python dry-run 2개, 기존 seed 7개/백필 5개도 통과. 외부 시세/LLM은 테스트 mock만 사용합니다.
